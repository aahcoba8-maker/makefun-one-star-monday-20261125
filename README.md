# One Star for Monday

A one-line entry for the [One Star for Monday](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61) bounty on make.fun.

## Entry

> One star. The server sat me at a table, forgot my order, and billed me a full week of work before breakfast.

A plain-text, single-line, 22-word one-star review of Monday written as if Monday were a restaurant: a table, a server who forgets the order, and a bill for a full week of work before breakfast.

## How it works

`main.py` (Python 3 standard library only) writes the review to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR` (or `/output` when present, otherwise next to the script). It asserts the kit gate first: 1–180 characters, at most 25 words, a single line.

```sh
python3 main.py
```
